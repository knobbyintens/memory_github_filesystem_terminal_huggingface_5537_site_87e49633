# Aurora Academic Pages starter

A small Jekyll-based academic personal website starter.

## Layout

- `_config.yml` – site and author configuration
- `_data/navigation.yml` – header navigation
- `_pages/` – standalone pages (about, CV, publications index)
- `_publications/` – publication collection, one Markdown file per paper
- `_includes/`, `_layouts/`, `assets/` – theme files

Copy this repository to start your own site and replace the placeholder content.
